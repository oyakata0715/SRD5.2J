# SRD5.2J
## この私訳は何のためにある？
あくまで個人用のSRD5.2の翻訳と、いずれ来るであろうSRD5.2翻訳プロジェクトのための練習場所を兼ねている。

## 翻訳方針
原則は以下のようならスタイルで翻訳する。
- SRD5.1にある呪文や特徴の日本語訳はそのまま引き継ぐ。
- SRD5.2で新たに追加された呪文やクラス特徴名の名前は意訳する。ただし原文の雰囲気をなるべく壊さないようにはする予定。
- クラス特徴や呪文の本文はなるべく機械翻訳ベースで翻訳する。ただし可読性や視認性を鑑みた結末意訳することがあるが、原則は機械翻訳とする。
- 略語（例:セーヴィング・スロー→セーヴ等)は原語が略語ならば略語を、そうでなければ正式名称で表す。
